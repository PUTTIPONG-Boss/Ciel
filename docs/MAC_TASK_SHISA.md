# งานสำหรับ Claude บน Mac: ทดสอบโมเดลภาษาญี่ปุ่น Shisa เทียบกับ qwen3:8b

> **วิธีใช้:** เปิด Claude Code บน Mac แล้วพิมพ์
> `cd ~/Ciel && git pull แล้วทำตาม docs/MAC_TASK_SHISA.md`

---

## ถึง Claude

### บริบท

- Ciel ใช้สไตล์อนิเมะ: พูดภาษาญี่ปุ่นและขึ้นซับไทย
- ผู้ใช้อยากให้ภาษาญี่ปุ่นเป็นธรรมชาติขึ้น มีคำรับฟัง (相槌) และคำแทรก (フィラー) และมีนิสัยกวนๆ ขี้หึง เย็นชาแบบน่ารัก (ไฟล์นิสัยอัปเดตแล้วใน v0.3.0)
- งานนี้คือทดสอบ **Shisa V2.1 Qwen3 8B** ซึ่งต่อยอดจาก Qwen3-8B และเทรนเพิ่มด้านภาษาญี่ปุ่น เทียบกับ `qwen3:8b` ที่ใช้อยู่ โดยใช้ไฟล์นิสัยจริงของ Ciel

**ข้อกำหนดในการทำงาน**

- **ห้ามเปลี่ยน `CIEL_MODEL` ใน `.env` เอง:** ให้ผู้ใช้อ่านรายงานแล้วตัดสินใจ
- **ห้ามแก้ไฟล์โค้ดใน `~/Ciel`:** แก้และ commit ได้เฉพาะไฟล์ใน `docs/` (ระบบอัปเดตอัตโนมัติจะหยุดถ้ามีไฟล์อื่นถูกแก้)
- **คุยกับผู้ใช้เป็นภาษาไทย**

## ขั้นที่ 1: เช็กว่าเป็นเวอร์ชันล่าสุด

```bash
cd ~/Ciel && git pull --ff-only && cat VERSION      # ต้องเป็น 0.3.0 ขึ้นไป
curl -s http://127.0.0.1:8080/api/health; echo
```

ถ้า `/api/health` ยังไม่เป็น 0.3.0 ให้รอประมาณ 1 นาที (ระบบอัปเดตอัตโนมัติจะดึงเอง) หรือรีสตาร์ทด้วย `launchctl kickstart -k gui/$(id -u)/com.ciel.server`

## ขั้นที่ 2: โหลด Shisa (ประมาณ 5GB)

ใช้ไฟล์ที่บีบอัดโดยใช้ข้อมูลภาษาญี่ปุ่นเป็นตัวปรับเทียบ (Japanese imatrix) ขนาด Q4_K_M:

```bash
ollama pull hf.co/dahara1/shisa-v2.1-qwen3-8b-UD-japanese-imatrix:Q4_K_M
ollama list
```

ไฟล์ใหญ่ ให้รันแบบ background แล้วรอจนเสร็จ ถ้าโหลดไม่ได้ ให้ใช้ไฟล์จากที่อื่นแทน:
`hf.co/mradermacher/shisa-v2.1-qwen3-8b-GGUF:Q4_K_M`
(ถ้าใช้ตัวนี้ ให้ใส่ชื่อนี้ใน `--models` ของขั้นที่ 3)

**ตรวจสอบ:**

```bash
ollama run hf.co/dahara1/shisa-v2.1-qwen3-8b-UD-japanese-imatrix:Q4_K_M "自己紹介を一文でお願いします"
```

ต้องได้คำตอบเป็นภาษาญี่ปุ่น

## ขั้นที่ 3: รันสคริปต์เทียบ (ประมาณ 5–15 นาที)

```bash
cd ~/Ciel && .venv/bin/python scripts/compare_models.py
```

- สคริปต์ถามคำถาม 10 ข้อกับทั้งสองโมเดล โดยใช้นิสัยจริงของ Ciel และตัวแยกบรรทัดตัวเดียวกับแอป แล้วเขียนรายงานไว้ที่ `docs/model-compare/<วันที่>.md`
- ระหว่างรัน RAM จะตึง เพราะ Ollama ต้องสลับระหว่างสองโมเดล ไม่ต้องตกใจ
- ถ้าเจอ error เรื่อง thinking ตัวโค้ดรองรับไว้แล้ว ระบบจะลองใหม่เองโดยไม่ส่งพารามิเตอร์นั้น

## ขั้นที่ 5: สรุปให้ผู้ใช้ (ภาษาไทย)

- อ่านรายงานแล้วสรุปตารางสรุป และยกตัวอย่างคำตอบที่ต่างกันชัดที่สุด 2–3 ข้อ
- ให้ความเห็นในฐานะคนอ่านภาษาญี่ปุ่นออก:
  - ฝั่งไหนพูดญี่ปุ่นเป็นธรรมชาติกว่า มี 相槌/フィラー และนิสัยคูเดเระ ขี้หึงชัดกว่า
  - ซับไทยของ Shisa ยังดีอยู่ไหม (Shisa ไม่ได้เทรนภาษาไทย นี่คือความเสี่ยงหลัก)
  - ความเร็วต่างกันแค่ไหน
- ถามผู้ใช้ว่าจะเปลี่ยนไปใช้ Shisa ไหม **ถ้าผู้ใช้ตกลง** ค่อยทำตามนี้:

  ```bash
  cd ~/Ciel
  sed -i '' 's|^CIEL_MODEL=.*|CIEL_MODEL=hf.co/dahara1/shisa-v2.1-qwen3-8b-UD-japanese-imatrix:Q4_K_M|' .env
  launchctl kickstart -k gui/$(id -u)/com.ciel.server
  curl -s http://127.0.0.1:8080/api/health; echo
  ```

  ถ้าภายหลังอยากเปลี่ยนกลับ ให้ตั้ง `CIEL_MODEL=qwen3:8b` แล้วรีสตาร์ทแบบเดียวกัน
- ถ้าไม่ใช้ Shisa ให้ลบเพื่อคืนพื้นที่ดิสก์ได้ด้วย `ollama rm <ชื่อโมเดล>` (ถามผู้ใช้ก่อน)
