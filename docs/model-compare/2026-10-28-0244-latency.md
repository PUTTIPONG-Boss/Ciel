## เทียบกับก่อนแก้ (v0.3.13 → v0.3.14) — สรุปสั้น

- **ผ่าน ≤4s: 11/16** (v0.3.13: 14/16) ข้อ 12–13 หลังตัดประวัติช้าผิดปกติ: first token 2.16s / **6.40s** และสร้างคำตอบเหลือ ~5.8 tok/s (ปกติ ~9) ยังไม่รู้สาเหตุ (prefill ปกติ 0.9s) ข้อ 5 (RAM/SSD) ตอบยาว 114 token
- **ตัดประวัติ:** ยังตัดครั้งเดียวที่ข้อ 11 (prompt 7,827 ก่อนตัด) ไม่บ่อยขึ้น ✅ แต่ prefill ข้อ 2+ ขยับเป็น 0.75–0.99s ตาม prompt ที่ยาวขึ้น (6,670 token)
- **ราคา probe:** เหลือ prefill ~0.86s + สร้าง 2 token 0.15s ≈ **~1s ต่อรอบ** ✅ (เดิม ~5.3s)
- **ว่าง 20 นาทีแล้วคุยต่อ ❌ อุ่นไม่พอ:** probe 3 ครั้ง (ทุก 5 นาที) แต่ข้อความแรกหลังว่าง **prefill 2.52s** (v0.3.13: 0.78s) เสียงเนื้อหาแรก 4.7s ข้อถัดไปกลับเป็น 0.78s → probe 2 token เบาเกินไป แนะนำกลับไปใช้ probe แบบ stream หลาย token (เช่น 1 run × 16) ซึ่งใช้ ~2.5s แต่ยกเลิกได้แล้ว
- **ส่งข้อความตรงจังหวะ probe:** ส่งทันทีที่ probe เริ่ม → first token **2.46s** (+1.6s), ส่งหลัง 1s → **1.47s** (+0.6s) การยกเลิกช่วยได้บางส่วน แต่ยังต้องรอ prefill ที่ค้างอยู่
