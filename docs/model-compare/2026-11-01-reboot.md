## สาเหตุที่ข้อความแรกช้า

`warm_up()` ใน `ciel/main.py` ตั้ง `warmed = persona` ก่อนรู้ผล และ `OllamaLLM.warmup` ถือว่าเสร็จแม้ได้ HTTP 500 จึงไม่ลองใหม่ prompt จึงไม่อยู่ใน cache จนกว่าจะมีข้อความแรก (keep-warm ตัวแรกจะมาหลังว่าง 150 วินาที แต่ข้อความของผู้ใช้มาก่อน)

## ข้อเสนอ (ฝั่ง Windows)

- ตอนเริ่มเซิร์ฟเวอร์ ให้รอ Ollama พร้อม (`GET /api/version` หรือ `/api/tags` ได้ 200) ก่อน warm-up และถ้า warm-up ได้สถานะไม่ใช่ 200 ให้ลองใหม่ทุก ~10 วินาที (เช่น สูงสุด 5 นาที) แทนการ log ว่า done
- log ควรเป็น WARNING เมื่อ HTTP ไม่ใช่ 200
