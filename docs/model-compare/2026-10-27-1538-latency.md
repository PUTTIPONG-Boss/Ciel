## Prefill ข้อที่ 2 ขึ้นไป: ยังช้า สาเหตุคือ chat template ของ Qwen3 ใน Ollama

วัดตรงกับ Ollama ด้วย `Persona.stamp` + `build_messages` ของ v0.3.3 (เก็บคำตอบลง history แบบเดียวกับ `main.py`):

| ข้อ | `/api/chat` + `think: false` (v0.3.3) | `/api/generate` + `raw: true` (ทดลอง) |
|---|---|---|
| 1 | 0.39s | (cold) |
| 2 | 0.94s | **0.64s** |
| 3 | 1.24s | **0.68s** |
| 4 | 1.29s | **0.72s** |

ส่งคำขอเดิมซ้ำทั้งก้อน prefill เหลือ 0.10s แปลว่า cache ทำงาน แต่ **prompt ของข้อถัดไปไม่ได้ต่อท้ายของเดิมพอดี** เพราะ template ของ `qwen3:8b` (`/api/show`) ทำ 2 อย่างเฉพาะข้อความล่าสุด:

1. เติม ` /no_think` ท้าย **ข้อความ user ล่าสุดเท่านั้น** (`if and $.IsThinkSet (eq $i $lastUserIdx)`) พอข้อถัดไป ข้อความ user เก่าไม่มี ` /no_think` แล้ว cache จึงหลุดตั้งแต่ข้อความ user ก่อนหน้า
2. ใส่ `<think>\n\n</think>\n\n` หลัง `<|im_start|>assistant` ตอนสร้างคำตอบ แต่คำตอบเก่าใน history ไม่มีส่วนนี้

ใส่ `<think>…</think>` นำหน้าคำตอบใน history ไม่ช่วย (ยัง 0.97s) เพราะข้อ 1 ยังอยู่

**ข้อเสนอแก้ (ฝั่ง Windows):** เปลี่ยน `OllamaLLM.stream` ไปใช้ `/api/generate` แบบ `raw: true` และเรนเดอร์ prompt เอง:

```python
def render(messages):
    out = "".join(f"<|im_start|>{m['role']}\n{m['content']}<|im_end|>\n" for m in messages)
    return out + "<|im_start|>assistant\n<think>\n\n</think>\n\n"
# options: + "stop": ["<|im_end|>"] ; เก็บคำตอบลง history เป็น "<think>\n\n</think>\n\n" + reply
```

แบบนี้ prompt ของทุกข้อจะต่อท้ายของเดิมพอดี prefill คงที่ ~0.65–0.7s ไม่โตตามบทสนทนา (ประหยัด 0.3–0.6s ต่อข้อ) และไม่ต้องพึ่ง `think: false`
(ผลทดลอง raw: คำตอบรูปแบบถูกต้อง `[concern]……お疲れです。` และไม่หลุดโหมดคิด) ข้อควรระวัง: warm-up ต้องเรนเดอร์แบบเดียวกัน ไม่งั้นข้อแรกจะ cold (~33s ตอนทดลอง)

## ข้อสังเกตเรื่องคำตอบ

- **ไม่มีบรรทัดรับคำเปล่าแล้ว (0/8)** บรรทัดแรกยาวเฉลี่ย 10.8 ตัวอักษร แต่ข้อ RAM/SSD ยังยาวเกิน
- **"สวัสดี" ยังลอกตัวอย่าง:** `おかえりなさい` + `三分遅刻です。数えてませんけど。` (มุก "สาย 3 นาที / ไม่ได้นับ" เดิม) ข้ออื่นเช่น `命令です。` ก็ยังมาจากตัวอย่าง
- **คำถามภาษาอังกฤษยังได้ซับไทย** (What should I name my new cat? → `...ชื่อแมวเหรอคะ`) แม้เปลี่ยนรูปแบบเวลาแล้ว น่าจะเพราะตัวอย่างทั้งหมดเป็นภาษาไทย ควรเพิ่มตัวอย่างคำถามอังกฤษ → ซับอังกฤษ 1 ชุด
- ข้อ RAM/SSD บอกว่า SSD คือ "ฮาร์ดดิสก์" (`メモリとハードディスクの違い`) ซึ่งไม่ถูกนัก
- `……お大事に。` (ดูแลตัวเอง/หายไวๆ) ไม่ค่อยเข้ากับเรื่องสัมภาษณ์งาน
- คำแปลครบ 17/17 ประโยค · เสียงสร้างไม่สำเร็จ 0
