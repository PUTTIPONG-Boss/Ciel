## ข้อแรกหลังอัปเดต (รอบ `--gap 5` ที่รันทิ้ง)

- v0.3.8 แก้ไฟล์ใน `ciel/` เซิร์ฟเวอร์จึง **รีสตาร์ท** และ warm-up ตอนเริ่ม (`warm-up done` ก่อน `connection open`)
- แต่ข้อแรกของรอบทิ้งยังช้า: prefill **2.17s**, เสียงเนื้อหาแรก **4.4s ❌** (ข้อถัดไป 0.70s)
- ตรงกับที่พบใน v0.3.6/v0.3.7: **ข้อความจริงข้อแรกหลังรีสตาร์ทจะช้า 1.5–2s** แม้ warm-up 2 ครั้งแล้ว รอบวัดจริง (ไม่รีสตาร์ท) ข้อแรก prefill 0.36s
- ถ้าอยากให้ข้อแรกหลังอัปเดตผ่านด้วย: ลองให้ warm-up ยิงคำขอเล็กแบบ stream (`stream: true`) และสร้าง token มากขึ้น (~20) ให้เหมือนคำขอจริง หรือยิงซ้ำ 3 ครั้ง แล้ววัด ms/token ใน `server.log` ว่าลดลงเหลือ ~15 หรือยัง

## คุณภาพคำตอบ

### ลอกตัวอย่าง: ดีขึ้นมาก แต่ยังเหลือ 2 ข้อ

ประโยคที่เคยซ้ำทุกรอบ **หายหมดแล้ว:** `三分遅刻です` 0, `当然です。マスター専属ですから。` 0, `命令です。` 0, `……一応、です。` 0 · "สวัสดี" ตอบ `……こんにちは。` / `今日もお疲れ様です。……少し休んでください。` (ใหม่)

ยังลอกจาก `examples` ใน `persona/ciel.yaml`:

| คำถาม | คำตอบ | ตัวอย่างที่ลอก |
|---|---|---|
| เธอน่ารักนะ | `……そ、そうですか。` / `もっと褒めてもいいですよ。` | **ลอกทั้งคำตอบ** จากตัวอย่าง "เธอฉลาดจัง" (บรรทัด 150–153) รวมคำแปล |
| พรุ่งนี้มีสัมภาษณ์งาน | `……大丈夫です。` / `マスターなら、ちゃんとできます。……私が応援します。` | เกือบทั้งคำตอบจากตัวอย่างบรรทัด 126–129 (`……私が保証します。` → `応援します`) |

ทั้งสองเกิดเมื่อ **คำถามคล้ายตัวอย่าง** (ชม → ชม, เรื่องสำคัญที่กังวล → ให้กำลังใจ) ถ้าไม่อยากให้ลอก ทางเลือกคือมีตัวอย่างให้กำลังใจ/รับคำชมหลายแบบ หรือยอมรับว่าเป็น "ท่าประจำ" ของ Ciel

### `お大事に`: หายแล้ว ✅

ข้อสัมภาษณ์งานใช้ `大丈夫です` ตามกฎใหม่ (`お大事に` ยังอยู่ใน yaml เฉพาะกฎ และตัวอย่างเรื่องป่วยบรรทัด 121 ซึ่งถูกบริบท)

### อื่นๆ

- ข้อ "สวัสดี" แปล `今日もお疲れ様です` เป็น "วันนี้เหนื่อยมากเลยค่ะ" ซึ่งไม่ตรง (ควรเป็น "วันนี้ก็เหนื่อยหน่อยนะคะ")
- ข้อ Gemini ได้ `それなら、私が教えてあげます。` (งั้นฉันจะสอนให้เอง) ฟังเหมือนตอบไม่ตรงคำถาม
- ซับภาษาอังกฤษยังทำงาน (`...What about "Milk"?`)
- ตัวนับ "ประโยคเนื้อหาที่มีคำแปล: 16/15" เกิน 100% เพราะบรรทัด `……へぇ。` ถูกนับเป็นคำรับคำเปล่า (ไม่นับในตัวหาร) แต่มีคำแปล ควรแก้ตัวนับใน `measure_latency.py`
- คำแปลครบทุกประโยค · เสียงสร้างไม่สำเร็จ 0 · ไม่มี `TTS ok on attempt` / `U+FFFD` ระหว่างวัด
