## สรุปและข้อเสนอ

- **450 ได้รูปแบบ 13/24 (< 20)** และยังพังเกือบครึ่ง → ตามเกณฑ์ในเอกสาร **ต้องปรับวิธีเทรน** ก่อนเพิ่มข้อมูล
- แต่ด้านความเข้าใจ 450 รอบนี้ **ไม่แพ้ `qwen3:8b` แล้ว** (✅3 vs ✅0) โดยเฉพาะ "เราพูดถึงเธอ", "จำเรื่องเมื่อวานไม่ได้" และเข้าใจว่ามาสเตอร์เป็นพิธีกร ซึ่งเป็นเรื่องที่ข้อมูลเทรนสอนตรงๆ
- แนวโน้ม: เทรนนานขึ้นรูปแบบดีขึ้น (100 → 300 → 450 = 2 → 11 → 13 จาก 24) แม้ val loss (10 ชุด) จะขึ้น → val loss บน val set เล็กไม่ใช่ตัวชี้วัดที่ดีสำหรับรูปแบบ ควรใช้ "รูปแบบถูก x/24" เป็นเกณฑ์เลือก checkpoint แทน
- ข้อเสนอวิธีเทรน (เลือกลองทีละอย่าง):
  1. เทรนต่ออีก ~300–450 iteration (`--resume-adapter-file training/adapters/final_450.safetensors`) แล้ววัดรูปแบบทุก 150 iteration ด้วย `eval_thai.py` (ตอนนี้ทดสอบ 1 โมเดลใช้ ~3 นาที)
  2. เพิ่ม `--num-layers` เป็น 32 (ทุกชั้น) หรือเพิ่ม rank LoRA เพื่อให้เรียนรูปแบบได้มากขึ้น (ใช้ RAM เพิ่ม ต้องลอง 20 iteration ก่อน)
  3. lr 1e-5 ค่อนข้างต่ำสำหรับ LoRA (ค่าที่ใช้ทั่วไป 1e-4–2e-4) ลอง 5e-5 อาจได้รูปแบบเร็วกว่า
- ระหว่างนี้ **ยังไม่ควรเปลี่ยน `CIEL_MODEL`** เพราะครึ่งหนึ่งของคำตอบจะมีบรรทัดที่ไม่มีเสียงหรือซับผิด
