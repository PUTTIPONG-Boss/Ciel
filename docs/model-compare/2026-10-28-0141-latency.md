### ราคาของ probe แต่ละรอบ (เรื่องที่รู้ว่าเสีย ~1s)

จาก `~/.ollama/logs/server.log` probe หนึ่งรอบเป็น 3 คำขอติดกัน GPU ไม่ว่าง **~5.3 วินาที** ไม่ใช่ ~1 วินาที:

| คำขอ | อ่านใหม่ | prefill | ใช้เวลารวม |
|---|---|---|---|
| 1. prompt บทสนทนา | 6–9 token | **1.2–1.5s (138–247 ms/token, GPU เย็น)** | 1.3s |
| 2. prompt + ข้อความ probe | 38 token | 0.67s | 2.3s (สร้าง 16 token) |
| 3. ซ้ำ (stream) | 1 token | 0.1s | 1.7s (สร้าง 16 token) |

- ถ้ามาสเตอร์ส่งข้อความตรงช่วงนี้จะต้องรอเพิ่ม **สูงสุด ~5 วินาที** โอกาสเกิด ~5.3/300 ≈ 2% ต่อข้อความแรกหลังว่าง
