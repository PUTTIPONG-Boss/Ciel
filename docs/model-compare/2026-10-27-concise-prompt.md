## สิ่งที่พบ

### 1. บรรทัดไม่มีเสียง เกิดจากตัวแยกบรรทัด ไม่ใช่เพราะพูดยาว (ฝั่ง Windows ควรแก้โค้ด)

`AnimeStream._detect_kind` ใน `ciel/speech.py` ตัดสินว่าบรรทัดไหนเป็นภาษาญี่ปุ่นจาก**ตัวอักษรตัวแรก**หลังแท็ก
บรรทัดอย่าง `[calm]RAMは一時保存、SSDは永久保存です。` ขึ้นต้นด้วยตัวอักษรอังกฤษ จึงถูกนับเป็นซับ ทำให้ไม่มีเสียงและซับต่อจากนั้นเลื่อนผิดคู่
บรรทัดไม่มีเสียงทั้ง 4 บรรทัดของ Shisa ในรอบแรกเป็นแบบนี้ทั้งหมด

ข้อเสนอแก้โค้ด (ทำได้อย่างใดอย่างหนึ่ง):
- ดูว่าทั้งบรรทัดมีคานะหรือคันจิไหม ถ้ามีและไม่มีอักษรไทย ให้ถือเป็นภาษาญี่ปุ่น
- หรือถ้าบรรทัดขึ้นต้นด้วยแท็ก `[emotion]` ให้ถือเป็นภาษาญี่ปุ่นเสมอ (ซับไม่มีแท็ก)

ระหว่างที่ยังไม่แก้ v3 เลี่ยงปัญหานี้ใน prompt ด้วยกฎ "ห้ามขึ้นต้นบรรทัดญี่ปุ่นด้วยตัวอักษรอังกฤษ ให้เขียน `えっと、RAMは…`" ผลคือบรรทัดไม่มีเสียงเหลือ 0 ทั้งสองโมเดล

### 2. ตอบสั้นลงได้ด้วยตัวอย่างที่สั้น

โมเดลเลียนแบบความยาวจากตัวอย่างมากกว่ากฎ ข้อเสนอจึงย่อตัวอย่างทุกอันให้เหลือ 1–2 คู่
- ข้อ "อธิบาย API" ตอบใจความประโยคเดียว แล้วถาม 「詳しく説明しますか？」 (ต้องการรายละเอียดไหม)
- เวลารวมของ qwen3 ลดลง 12.9 → 9.3–11.5 วินาที

### 3. ความเป็นหุ่นยนต์รับใช้

เพิ่มคำตอบรับแบบหุ่นยนต์ เช่น `はい。` / `了解です。` และ "……命令です。" (นี่คือคำสั่ง) หรือ "今の、記録しておきます。" (ขอบันทึกไว้)
แล้วให้ความเป็นมนุษย์โผล่มาแค่ประโยคท้ายสั้นๆ ตัวอย่างจาก v3 (qwen3):

- เหนื่อย → 「……寝ましょう。今すぐ。」「……仕事は、明日に回してください。」
- ไปกินข้าวกับรุ่นน้อง → 「……ふーん。了解です。」「帰る時間だけ、教えてください。……一応、です。」
- สัมภาษณ์งาน → 「……焦らず、マスター。私がいますから。」

### 4. Shisa ยังไม่เหมาะ

- ภาษาญี่ปุ่นของ Shisa สร้างสรรค์กว่าบางข้อ เช่น 「……もしかして、私より可愛い子ですか？」 (หรือว่าน่ารักกว่าฉัน?)
- แต่**ซับไทยไม่เสถียร**: รอบ v3 ตอบซับเป็นภาษาอังกฤษ 3/9 ข้อทั้งที่ถามเป็นไทย และมีคำผิดในภาษาญี่ปุ่น เช่น 「熱気分」
- บางครั้งเข้าใจบริบทผิด เช่น ตอบว่า 「本当にごめんなさい」 ตอนมาสเตอร์ลืมกินข้าว

**ข้อแนะนำ:** ใช้ `qwen3:8b` กับนิสัยแบบ v3

## ปัญหาที่ยังเหลือ (qwen3 + v3)

- ข้อ 1 "สวัสดี" ลอกตัวอย่างทุกคำ เพราะคำถามเหมือนตัวอย่าง ถ้าไม่อยากให้ซ้ำ ควรมีตัวอย่างทักทายหลายแบบ หรือตัดตัวอย่างทักทายออก
- ข้อ 10 ถามเป็นภาษาอังกฤษแต่ได้ซับไทย
- บางประโยคยังแปลไม่ตรงทั้งหมด เช่น 「眠る時間、しっかり確保してください」 แปลแค่ "นอนให้พอค่ะ"

## วิธีนำไปใช้ (ฝั่ง Windows)

1. เทียบ `docs/model-compare/ciel-concise-proposal.yaml` กับ `persona/ciel.yaml` แล้วนำส่วน `identity`, `personality`, `speech`, `rules`, `anime_rules` และ `examples` ไปใช้
   (ส่วน `voice`, `emotions`, `native_examples` คงไว้เหมือนเดิม)
2. แก้ `_detect_kind` ตามข้อ 1 ถ้าแก้แล้ว กฎเรื่อง "ห้ามขึ้นต้นด้วยตัวอักษรอังกฤษ" จะเอาออกก็ได้
3. push ขึ้น `main` แล้ว Mac จะอัปเดตเองภายใน 1 นาที (แก้แค่ persona ไม่ต้องรีสตาร์ท แค่กด "แชทใหม่")
