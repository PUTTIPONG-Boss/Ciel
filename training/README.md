# Fine-tune Ciel (LoRA)

สอน qwen3:8b ให้เข้าใจภาษาไทยแบบที่มาสเตอร์พูดจริง (เรา/เธอ/เขา, "เมื่อกี้…", "อันหลัง", ภาษาพูด) และตอบในรูปแบบของ Ciel โดยใช้ system prompt สั้น (`Persona.tuned_prompt`, ~630 token) และไม่มีตัวอย่างใน prompt (prompt เต็มตอนนี้ ~6,600 token) เปิดใช้ด้วย `CIEL_TUNED=true`

| ไฟล์ | คืออะไร |
|---|---|
| `dialogs/*.yaml` | บทสนทนาหลายรอบที่ใช้เทรน (แก้/เพิ่มที่นี่) |
| `build_dataset.py` | ตรวจทุกคำตอบด้วย parser เดียวกับแอป แล้วสร้าง `data/train.jsonl`, `data/valid.jsonl` (รูปแบบ chat ของ mlx-lm) |
| `eval.yaml` | บทสนทนาทดสอบที่ **ไม่อยู่** ในข้อมูลเทรน ใช้กับ `scripts/eval_thai.py` |
| `Modelfile` | นำโมเดลที่เทรนแล้วเข้า Ollama เป็น `ciel-qwen3` |

ขั้นตอนเทรนบน Mac: [`docs/MAC_TASK_FINETUNE.md`](../docs/MAC_TASK_FINETUNE.md)

## เขียนบทสนทนาเพิ่ม

```yaml
- turns:
  - u: "ข้อความของมาสเตอร์ (ไม่ต้องใส่วันเวลา สคริปต์ใส่ให้)"
    c: |-
      [calm]……ประโยคแรกสั้นๆ。
      ประโยคที่สอง。
      >> 1 ...คำแปลบรรทัดแรก
      >> 2 คำแปลบรรทัดที่สอง
  - at: "23:40"        # ไม่บังคับ: เวลาของข้อความนี้ ("HH:MM" หรือ "YYYY-MM-DD HH:MM") ใช้เมื่อคำตอบพูดถึงเวลา/วัน
    u: "ข้อความถัดไปในบทสนทนาเดียวกัน"
    c: |-
      ...
```

- คำตอบต้องเหมือนที่อยากให้ Ciel ตอบจริงทุกตัวอักษร: บรรทัดแรกมีแท็ก ไม่เกิน ~12 ตัวอักษร (เกิน 16 = error), 1–3 ประโยค, คำแปลมีเลขและแปลตรงบรรทัดนั้น
- บรรทัดญี่ปุ่นที่ไม่มีแท็กต้องขึ้นต้นด้วยตัวอักษรญี่ปุ่น (`iPadでは…` จะกลายเป็นซับ ให้เขียน `タブレットでは…`)
- ข้อความภาษาอังกฤษ → ซับอังกฤษ, อื่นๆ → ซับไทย (สคริปต์เช็กให้)
- Ciel จำได้แค่ในแชทนี้ ห้ามให้ตัวอย่าง "จำเรื่องเมื่อวาน" หรือทำสิ่งที่ทำไม่ได้ (ตั้งปลุก เปิดเพลง ดูพยากรณ์อากาศ)
- เนื้อหาต้องหลากหลาย: โมเดลลอกประโยคที่เห็นบ่อย (เคยลอก `もっと褒めてもいいですよ` และเรื่องชื่อโปรเจกต์จากตัวอย่าง)

```bash
python training/build_dataset.py --check   # เช็กอย่างเดียว
python training/build_dataset.py           # สร้าง data/
```

**แก้ persona แล้วต้องเทรนใหม่ไหม:** prompt สั้นมีแค่ตัวตน บุคลิก และรูปแบบคำตอบ แก้ `identity`/`personality` ได้เลย (มีผลทันที) ส่วน `rules`, `anime_rules`, `examples` ไม่อยู่ใน prompt สั้น ถ้าแก้ต้องแก้ข้อมูลเทรนแล้วเทรนใหม่ให้โมเดลเรียนรู้
